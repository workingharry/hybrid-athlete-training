# 0003. 採用 Foster sRPE × 時長 (AU) 作為雙軌唯一定量貨幣

## 狀態
Accepted

## 背景與決策
耐力路跑（心肺有氧代謝）與重量訓練（中樞神經與肌纖維微創傷）具有根本不同的代謝與生理機制。我們決定採用 Foster's Session RPE (sRPE $\times$ 分鐘數, AU) 作為系統雙軌唯一的負荷貨幣；跑步透過心率區間動態推導等效 sRPE 並經由個人中位數偏差修正，重訓則透過極簡 15 秒打卡滑桿輸入。

## 原因與取捨
此決策放棄了主流健身軟體對組數、重量、次數 (Volume Load) 或 VBT 速度的微觀追蹤，也放棄了純依賴心率 TRIMP/EPOC 的穿戴模式。取捨的考量在於：極簡打卡能將重訓輸入摩擦力壓至 15 秒內，大幅保證長期使用依從性，同時在宏觀決策層將有氧與肌力疲勞正規化至同一度量衡，使 ACWR 與生理準備度仲裁得以成立。
