# 0006. 啟發式疲勞管理定位校準與真實數據提早回放架構

## 狀態
Accepted

## 背景與決策
在收到《混合訓練排課 App PRD v3.0 方向審查》反饋後，我們對運動科學理論邊界與專案實施順序進行了關鍵校準：
1. **定位由「消除運動學干擾」校準為「雙向殘餘疲勞與微創傷管理 (Heuristic Fatigue Management)」**：
   運動生理學中並行訓練干擾效應（Interference Effect）本質為長期分子適應（mTOR vs AMPK）與爆發力減損，深蹲與路跑的短期交互影響主要源於 DOMS、結締組織微創傷與中樞神經疲勞。我們決定將所有肌群冷卻參數與 ACWR 閾值明確標記為「工程啟發式預設值 (Configurable Heuristics)」，並提供可配置結構體，杜絕過度宣稱科學定論。
2. **驗證前移：真實 HealthKit 數據回放自 Phase 5 提前至 Phase 1 結束時**：
   為防範「程式碼邏輯自洽但不具實際產品價值」的同義反覆，我們將 4～8 週真實 HealthKit 數據的離線回放審查移至 Phase 1（完成 `HealthKitAdapter` 後立即執行），以人工雙盲評估每日建議之「合理滿意度 $\ge 85\%$」作為核心閘門，而原先的「三大規則零違規」降級為純內部代碼回歸測試。
3. **負荷命名與 ACWR 軟性警示定性**：
   因應 Impellizzeri (2020) 等學者對 ACWR 數學耦合與傷病預測力之學術批評，系統明確將 ACWR 定位為「短期增量速率之啟發式輔助參考」，嚴禁作為硬性阻斷閘門；並在概念上澄清為 7 天急性 / 28 天慢性簡單移動平均負荷 (SMA)。

## 原因與取捨
此決策放棄了誇大科學護城河的行銷話術，換取了更扎實的學術誠實度（Intellectual Honesty）與極早期的實機真實數據驗證，大幅降低了後期 UI 與持久層返工的工程風險。
